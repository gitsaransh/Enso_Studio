# Enso Studio v2 (Replica)

This project is a Next.js replica of the Rocket AI generated design.

## Getting Started

1.  Navigate to this directory:
    ```bash
    cd enso-v2
    ```

2.  Install dependencies (already done):
    ```bash
    npm install
    ```

3.  Run the development server:
    ```bash
    npm run dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) with your browser.

## Notes

-   **Reconstructed Files**: `src/app/page.tsx` was reconstructed to use the provided components (`Header`, `EnsoAnimation`, `Footer`) as the original code was missing.
-   **Icons**: A dynamic `AppIcon` component was created to map string names to Heroicons.
-   **Analytics**: Rocket AI analytics scripts were removed from `layout.tsx`.
